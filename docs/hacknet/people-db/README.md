# 人物数据库档案

Hacknet 游戏内各数据库（学历库、医疗库、死刑犯库）中可查询到的 NPC 人物档案。数据提取自游戏 `Content/People/` 目录的 XML 档案文件。

> 说明：这些人物大多作为**任务目标**出现在 CSEC / 各阵营任务中（如删除学术记录、篡改医疗档案、修改死刑犯记录）。与剧情主线人物（Bit、Naix、Kaguya 等）不同，详见 [人物与剧情档案](/hacknet/characters/)。
>
> ⚠️ 本页全部数据均为**游戏内虚构设定**（由游戏程序化生成或开发者编写）。即使是致敬开发者本人的彩蛋档案，其中的个人信息（含医疗记录）也纯属虚构，不代表任何真实人物的实际情况。
