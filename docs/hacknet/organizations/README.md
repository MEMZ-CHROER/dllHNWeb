# Hacknet 组织历史

Hacknet 的世界里，黑客从不孤单——几乎每个玩家都会先后加入一个或多个组织。这些组织各有各的宗旨、招募流程与行事风格，并在主线剧情中扮演关键角色。本文基于游戏数据与剧情还原各组织的历史。

| 组织 | 类型 | 玩家何时接触 |
|---|---|---|
| **Entropy（熵）** | 黑客行动主义 | 主线第一阶段，首个加入的组织 |
| **CSEC** | 雇佣黑客 | 主线中段，经测试加入 |
| **lelzSec** | 地下隐藏组织 | 反黑分支（可选） |
| **EnTech** | 科技公司 | 贯穿主线（Bit 的雇主） |
| **Bibliotheque** | 团队化组织 | Labyrinths DLC 主线 |

---

## 🌀 Entropy（熵）

**Entropy** 是玩家在游戏中加入的第一个黑客组织，一群崇尚混乱与反抗的黑客行动主义者。玩家经 **Bit** 遗言的引导、通过其测试服务器后加入。

### 组织宗旨

Entropy 资源服务器里存有组织的「宗旨」（`Mantra.txt`）：

> **Entropy 宗旨**
>
> 我们的组织建立在三个准则之上。我们力求做到这三点：
>
> 1. 在任何事情上努力追求正义和公正
> 2. 我们追求创造和分享，而不是毁灭
> 3. 永远不要为停滞不前而寻找理由
>
> 我们组织不会接受，也不允许违背这三条准则的成员，违反这三条准则的成员将会被直接开除。

### 加入方式

- **第一项测试**：通过 Entropy 的入门考试（由 Bit 的测试服务器自然引出）
- **第二项测试**：瘫痪一家与 Entropy 对立的新闻网站的新闻版块（"不破坏无关服务器"是底线）
- 通过后由联络人 **Tex** 正式接纳

### 主要行动与结局

- **攻击对立媒体**：Entropy 的首要打击目标是 **Tom Wilkins** 的新闻站——Wilkins 公开主张「我们必须阻止 Entropy」。Entropy 一度要求玩家瘫痪其服务器。
- **最终任务——根除 HacknetOS**：Entropy 盯上了一家基于已故黑客 **Bit** 的研究、正在开发名为 **HacknetOS** 的操作系统的公司。Entropy 认为这种系统让"最基础的用户只需简单训练就能入侵"，是对整个信息世界安全的巨大威胁，要求玩家彻底根除该项目。
- **结局**：最后任务结束后组织全面隐匿——"任务结束后我们都没法再保持联系了，这太冒险了"。

> 🔑 **剧情地位**：Entropy 阶段是玩家黑客生涯的起点，也是主线转折的伏笔——它把玩家引向 Bit 留下的真相（详见 [主线剧情](/hacknet/story/)）。

## 🔒 CSEC

**CSEC** 是一个只允许被邀请加入的雇佣黑客组织，由资深黑客与信息安全专家组成。

> CSEC 组织是一个只允许被邀请加入的组织，由资深黑客和信息安全专家组成。我们向优秀的人才提供大量的知识和资源，以此来组建一个互相学习、共同进步的良好团体。
> ——CSEC 管理员

### 招募流程

1. **邀请**：由组织成员申请（玩家的邀请正是 **Bit** 生前提交的）
2. **自动测试（Gauntlet）**：依次攻破 CSEC 的测试服务器
3. **肯德基试炼**：入侵啃得鸡服务器，窃取 **11 种秘密香料配方** 并上传至 CSEC 共享服务器
4. **正式加入**：获得 CSEC 主服务器与资源服务器权限，任务板完全开放

### 核心成员

CSEC 服务器管理员账号名单：

| 成员 | 说明 |
|---|---|
| **Bit** | 已故成员，玩家的推荐人；在 CSEC 留有未完成的调查 |
| **Vap0r** | 招募与测试的实际执行者（"CSEC 管理员"署名） |
| **Tex** | 与 Entropy 同名的联络人（两个组织间存在微妙联系） |
| **Jayja / Reptile / PLHunter / Zeedox** | 其他管理员账号 |

### 运营机制

- **任务板（MainHub）**：匿名客户（`#CLIENT#`）发布任务，成员自由接单——Decrypt 解密系列、起搏器系列、核心数据库（ISP Management、Universal Medical 等）都属于这一生态。
- **内部暗流**：CSEC 对系统安全"看得太重"，导致 **V**（Bit 的朋友）只能匿名推动 **bit 系列任务**，引导玩家完成 Bit 未竟的调查（详见 [主线剧情](/hacknet/story/)）。

## 🕶 lelzSec

**lelzSec** 是主线隐藏组织，仅通过 **反黑分支** 可加入——在 **Naix** 顺着你的日志反入侵后，如果你选择反黑回去并摧毁 `x-server.sys`，Naix 认输后便会引荐你入伙。

> 好吧，我之前真的是小瞧你了……经过我和其他人的讨论后，我们一致同意你入伙。你的 IP 地址已经被我们列入白名单了。
> ——Naix

- **成员**：Naix 主导，另有匿名成员共同决策
- **机制**：IP 白名单准入，核心服务器 `lelzSecHub`
- **试炼**：北极星试炼（**Polar Snake**）——从 Shrine 到 Patience / Haste / Diligence / Focus 再到 Head，考验玩家的耐心与专注
- **社交**：`/el` 论坛作为组织信息板

> 🕶 **地位**：与 Entropy、CSEC 相比，lelzSec 更小、更隐蔽，成员以能力与互信维系，是主线支线中最"纯粹"的地下组织。

## 🏢 EnTech

**EnTech** 不是黑客组织，而是一家科技公司——但它是整条主线真正的"幕后黑手"，也是 **Bit** 死亡真相的所在。

- **Bit 的雇主**：Bit 生前在 EnTech 工作，创造了 **PortHack**（端口破解工具）
- **危险项目**：EnTech 基于 Bit 的研究，正在开发 **HacknetOS**——一种能让人人都成为入侵者的操作系统（Entropy 的最终目标正是根除它）
- **Bit 之死**：Bit 发现了 EnTech 的危险项目，也因此丧命，留下了指向真相的加密线索
- **玩家的结局**：在 **V** 的引导下，玩家潜入 EnTech 基础设施（`156.151.x.x` 网段），最终摧毁 **`Porthack.Heart`**——PortHack 系统的核心，让 PortHack 再也不能被用作武器

> 🔑 **剧情地位**：EnTech 是 Bit 线（V 系列）的核心舞台，详见 [主线剧情](/hacknet/story/)。

## 📚 Bibliotheque（Labyrinths DLC）

**Bibliotheque**（法语"图书馆"）是 DLC《Labyrinths》中的团队化组织，风格与主线各组织截然不同——它更像一支分工明确的小队，通过 **IRC 频道** 协作。

- **成员**：
  - **Kaguya** —— 负责管理与侦查，"确保大家各司其职，实现我们的目标"，同时提供成员所需的工具与信息
  - **Coel** / **D3f4ult** —— 前线执行任务的成员
- **加入方式**：通过试炼后加入，被加入 IRC 频道白名单
- **运营**：合同（Contract）按先到先得分配，玩家可随时在任务栏接取
- **氛围**：相比主线的神秘与对抗，Bibliotheque 的成员更直接、更"团队"——欢迎词就是一句简单的"@channel，欢迎加入我们"
