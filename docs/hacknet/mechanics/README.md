# 核心机制详解

基于 Hacknet 游戏源码的技术细节分析。


## 安全等级系统

每台服务器有安全等级（0-10+），决定其防御强度：

| 等级 | 防御 |
|---|---|
| 0 | 无防御，直接访问 |
| 1-3 | 开放端口，无追踪/防火墙/代理 |
| 4 | 激活**追踪系统** |
| 5+ | 代理 + 防火墙 + 追踪 |

所需的破解端口数 = 安全等级 - 1（等级 5+ 时会额外减少）。


## 端口破解流程

1. **`scan`** — 发现目标服务器的开放端口
2. **`probe`** — 查看端口详情和服务类型
3. **运行破解程序** — `exe SSHcrack 22`、`exe FTPBounce 21` 等
4. **重复** — 直到打开的端口数 ≥ `portsNeededForCrack`
5. **`exe PortHack`** — 获取管理员权限（耗时 6 秒，显示密码滚动动画）

破解程序位于 `/bin` 目录，通过 `scp` 从已破解的服务器获取。

某些服务器会伪装端口号，需要先探测真实端口映射。


## 防火墙系统

防火墙出现在安全等级 5+ 的服务器上：

- **密码长度** = 6 + 复杂度（复杂度 = 等级 - 5）
- **密码内容**：随机大写字母数字组合
- **`analyze` 命令**：每次分析揭示更多密码字符。首次分析每 20 位隐藏一位，后续每次修复 3 个位置
- **分析耗时递增**：首次 `0.08s`，后续每次增加 `0.06s` + 额外延迟
- **`solve <密码>` 命令**：输入完整密码（不区分大小写），错误会提示"字符太多/太少"

如果管理员权限被回收，防火墙会重置。


## 代理系统

代理是一种**时间型**防御，在等级 5+ 的服务器上出现：

- 基础压测时间：**30 秒**
- **Shell** 命令创建一个远程 Shell 来压测代理
- Shell 消耗 RAM（约 40M）来维持运行
- 压测完成后才能运行 PortHack
- Shell 会在目标服务器上留下连接日志：`[IP]_Opened_#SHELL`


## 追踪系统

追踪系统在安全等级 4+ 的服务器上激活：

- **基础追踪时间**：`15s × max(10 - 等级, 3)`
- 追踪进度在屏幕左下角以百分比显示（100.00 → 00.00）
- 到达 00.00 时触发**危险序列**（游戏结束）
- **停止追踪的方法**：
  - 断开连接
  - 运行 **TraceKill.exe**（冻结追踪计时器，600 RAM）
  - 追踪极度接近时断开连接可获得 `trace_close` 成就


## 管理员系统

获取管理员权限后，可执行所有操作。断线后：

- **BasicAdministrator** 会随机延迟后（最长 20 秒）重置所有端口、收回管理员权限、重置密码
- 端口会重新关闭，防火墙重置
- 需要重新破解才能再次获取权限


## 系统日志

- 所有操作记录在目标服务器的 `/log` 目录
- 使用 `rm *` 清空日志
- 文件名以 `@` 开头，后面跟随着**ip**的为日志文件
- 但推荐全部 `rm` 掉
- **游戏中每次入侵后务必清日志**——这是游戏机制的一部分，也是剧情的关键教训


## RAM 管理

- 每个运行的程序占用 RAM
- Shell 约 40 单位
- 总 RAM 有限，耗尽后无法启动新程序


## Labyrinths DLC 专属机制

DLC《Labyrinths》引入了主线没有的新机制，主要在 Bibliotheque 团队任务中使用：

### 合同系统（Contract）

- 团队通过 **DHS 任务板**发放合同
- 合同**按先到先得分配**，玩家可随时在任务栏接取
- 任务是团队协作性质——你负责核心渗透，队友在后台同步推进

### IRC 频道协作

- Bibliotheque 成员通过 **IRC 频道**协作，日常沟通与任务情报都在频道内进行
- 加入团队后会被加入 IRC 频道白名单
- 任务情报（如炼金术士线发现的线索）通过聊天频道共享给全队

### 内存取证（MemForensics）

- **内存取证工具**把目标整个 RAM 状态拷贝出来，用工具筛选出有用数据
- 用于分析内存转储文件，是 DLC 专属的调查手段
- ⚠️ 注意：使用内存取证工具本身可能被"卖家"记录，是一种潜在陷阱

### 非标准安全配置

- DLC 部分目标使用**非标准配置**：自定义端口(**例如**`SSH 端口，端口号为33`)、非常规服务器设置（"定制狂"任务线）
- 破解时不能只依赖端口破解流程，需要针对非常规配置探索
- 专用**白名单服务器**会拒绝外部连接（太平洋航空预售服务器），需要团队配合或寻找替代进入点
